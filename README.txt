🛰️ 星际快递员 · 试玩版 v0.3.6
================================

【怎么玩】
双击 index.html 就能玩（用浏览器打开，推荐 Chrome / Edge）。

【安卓 / 苹果试玩】
推荐把 dist 文件夹发布到支持 HTTPS 的静态网站，再把网址发给朋友：
  安卓：用 Chrome 打开网址 → 浏览器菜单 →“安装应用”或“添加到主屏幕”
  苹果：用 Safari 打开网址 → 分享按钮 →“添加到主屏幕”
首次联网打开后，游戏会缓存到设备；之后可从主屏幕以独立窗口启动。

同一 Wi-Fi 下临时测试也可以在电脑上启动静态文件服务器，再用手机访问“电脑局域网 IP:端口”。
这种方式适合快速试玩；正式分享仍建议使用 HTTPS 网站。

【第一关 · 地球同步卫星】
跟着屏幕下方的分步指引，把卫星送上地球同步轨道：
  ① 进入环绕轨道 —— 短按起飞，高度 40–60 u 时向右压平，让黄色预测线闭合
  ② 抬升轨道     —— 沿速度方向点火，把远地点抬进金色环形带
  ③ 形成同步轨道 —— 在远地点再点火，让近、远地点都进入金色带，并匹配地球自转
  ④ 释放卫星     —— 确认顺行同步轨道稳定后按 E
                     （进阶挑战：开进绿色扇形"发射点正上空"再释放）
教学关燃料无限，大胆尝试！坠毁会回到当前阶段重来，不从头再来。

【第二关 · 载人航天返回】
从同步轨道开始，反推降低近地点，进入大气层后自动打开降落伞：
  ① 反推降轨 —— 机头朝速度反方向点火，让预测轨迹扎进地球
  ② 再入减速 —— 低空前把速度控制下来，等待降落伞打开
  ③ 垂直着陆 —— 机头朝上轻点推进，以 ≤17 的相对速度触地
落入绿色着陆区可达成完美着陆。

【操作】
  ↑ / W      点火推进（减速也是它：掉头朝尾向点火）
  ← → / A D  转向 / 调整姿态夹角
  C          切换姿态模式：随速偏转(默认) / 手动转向 / 纯惯性
  V          切换姿态表盘：世界固定 / 速度向上 / 机头向上
  T          开关未来轨迹辅助线（黄色虚线 = 松手后会怎么飞，橙圈=远地点 蓝圈=近地点）
  K          切换“跟随飞船 / 地球静止”视角
  B          切换“轨道雷达 / 全局导航 / 关闭小地图”
  E          释放卫星（手机在最后阶段点击屏幕下方“释放卫星”）
  H          隐藏 / 显示任务文字（不会改变游戏难度）
  M          切换飞行辅助 / 挑战模式
  按住空格    8 倍速（长距离等待用）
  P           暂停 / 继续
  L           切换第一、第二关
  滚轮        缩放视野
  拖动画面    跟随模式松手后自动回到飞船；地球静止模式松手后停留在观察位置
  双指缩放    手机上双指捏合缩放地图，缩放中心跟随两指中点
  手机触控    左转 / 推进 / 右转按钮支持多指同时长按，可边转向边点火
  R          回到当前阶段检查点
  Shift+R    从本关开头重新开始

【新手友好设计】
  🕐 推进时自动进入子弹时间，从容调整
  📈 黄色辅助线实时显示未来轨迹，标注近/远地点
  💡 游戏内只保留关键词和关键数值，减少阅读对飞行操作的打断
  📖 每关首次进入会显示“怎么做 / 为什么 / 成功标志”科普；之后点击工具栏 i 随时查看
  🛰️ 双视角可在子弹时间中拖走镜头，专门观察远地点 / 近地点的变化
  ⛽ 教学关燃料无限，生命维持系统未启用
  ✨ 当前步骤需要的按钮会持续发光；不确定时先按发光按钮
  📱 手机飞行界面只保留视角、地图、暂停和倍速，其余设置位于暂停菜单
  🖱️ 推进与左右转向分区放置，键盘与触屏均可游玩

【姿态模式说明】
  随速偏转：机头始终和速度方向保持你设的夹角，←→ 调夹角。起飞自动垂直，入轨自动跟随
  手动转向：直接控制机头角度，简单直接
  纯惯性：  松手保持自旋，反向按键刹车，高手向

【缩比物理说明】
HUD 使用游戏单位 u / u/s，不代表真实米制数值。轨道机动的方向与因果关系遵循真实轨道力学，但天体尺寸、引力和时间均经过缩放。
