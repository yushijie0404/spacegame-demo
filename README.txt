【v1.5.0 天体美术、响应式目录与手机目标导航】
月球与火星升级为一次生成并缓存的卡通表面纹理：月球加入月海、环形山、撞击射纹和潮汐锁定信标，火星加入峡谷、沙丘、暗色高地、极冠和大气边缘。双星与三体恒星增加表面对流弧、恒星黑子、光球边缘和轻量日珥；空间站增加双层桁架、四块分格太阳翼、居住舱、补给舱、对接口、天线碟和导航灯，并在远景中只放大绘制尺寸而不改变碰撞盒。黑洞增加低亮度极轴喷流、光子副环和旋转热点，仍保持白炽吸积盘，不使用彩色盘面。以上细节都复用缓存或低路径数绘制，手机轻量模式不会恢复昂贵模糊特效。

任务目录改为真正的响应式翻页：手机竖屏把十关纵向排列，使用原生上下滑动；横屏与电脑继续横向排列并左右滑动。鼠标按住拖动会自动识别当前方向，触屏交给系统原生滚动，避免卡片误触和滚动条突兀。402×714 竖屏与 844×390 横屏浏览器实测均通过。

手机飞行画面新增统一的“目标锁定指示”：当前任务目标在画外时，屏幕边缘显示方向、名称和距离；目标已在画内但缩得太小时，使用屏幕空间准星保证可辨认，不再被迫把飞船与目标一起缩成小点。短竖屏小地图从易被 HUD 遮挡的左上角移到中下区域，并由 76px 提升到 92px；普通竖屏提升到 116px。右上遥测默认精简为速度、相对状态、距离和一条关卡关键指标，点击面板可展开全部数据；展开时短屏小地图自动移到左侧避让。十九组物理、任务、UI、性能与视觉回归全部通过，浏览器未发现运行错误。

【v1.4.4 转向控制与地球视觉升级】
左右转向键不再使用会随手机字体变化的“↶/↷”字符，改为内置的左右镜像 SVG 姿态控制图标：弧形运动轨迹、青色方向箭头、中心姿态点和按压反馈都保持一致；按钮本体增加深蓝仪表质感、内圈和高亮边框，手机轻量模式使用无模糊的纯色版本，避免为了美观重新增加合成开销。

地球从每帧拼接几个简单椭圆升级为一次生成并缓存的 1024 像素卡通纹理：加入可辨认的美洲、欧亚非、澳大利亚和格陵兰轮廓、深浅地形、海洋层次、海面纹理、南北极冰盖与三条大气云带；运行时只旋转缓存纹理，并叠加大气辉光、昼夜渐变、明亮晨昏边缘和发射点。桌面与手机共享同一套美术，手机采用低成本阴影，细节更多但每帧路径数量更少。十九组物理、任务、UI、性能和视觉回归全部通过。

【v1.4.3 iPhone HUD 卡顿根因修复与 iPad 横屏布局】
根据安卓、iPhone 和 iPad 实机性能报告定位到卡顿不在物理或轨迹：iPhone 第九、十关物理约 0.1～0.3 ms，HUD 却达到约 400 ms。根因是 fitText 曾用 parseFloat 读取类似“800 15px”的字体字符串，把字重 800 误当成 800px 字号；长中文提示放不下时，每行、每帧会执行上千次 measureText。现在改为准确提取 px 字号，按宽度一次缩放并使用二分截断，自动回归确认一条超长提示最多只需 12 次文字测量。

宽屏触控设备不再沿用桌面右下角的紧凑按钮组：iPad 横屏的左右转向键移到左下方，推进键单独放到右下方，扩大间距和触控尺寸。燃料、生命维持与姿态信息会根据触屏高度移到姿态表下方或屏幕中部，不再被底部按钮遮住。每次进入或重开关卡会清空性能采样，长帧报告也会包含尚未结束的当前五秒窗口，避免上一关峰值污染下一关。十八组回归测试全部通过。

【v1.4.2 手机性能诊断与模块化起步】
新增独立的 runtime-performance.js 运行诊断模块，开始把平台与性能工具从 31 万字节的单文件游戏中拆出，同时不改变十关的物理、操作手感或结算规则。现在会分别采样物理更新、世界图层绘制、高清 HUD、轨迹重算和整帧主线程工作的平均/峰值耗时，并按五秒窗口统计超过 42 ms 的长帧比例与最慢帧间隔。

暂停菜单会持续显示这些分项数据，并新增“复制手机性能报告”按钮；在安卓或苹果上复现卡顿后暂停并点击按钮，即可把设备、画面倍率、当前关卡、姿态模式、轨迹/指引状态和全部耗时一次复制出来。外置模块已经加入离线缓存与一键发布必需文件检查，避免 GitHub Pages 更新后缺少诊断脚本。十八组物理、任务、UI 与性能回归全部通过。

【v1.4.1 黑洞救援圈结算修复】
修复第九关飞船已经向外穿过绿色救援圈，但逃逸能量仍为负时既不成功也不失败、可以无限飞在圈外的判定缺口。现在向外穿圈会立即分流：逃逸能量大于 0 直接成功；能量仍小于或等于 0 时，救援圈和小地图标记变红，HUD 明确提示“还会掉回来”，保留约 1 秒用于读取状态后判定失败。失败说明会显示当前能量与束缚轨道尺度，并引导玩家回到紫色近点沿速度方向点火。检查点会清除无效出圈状态，阶段回退后可以正常重试。十七组回归测试全部通过。

新增无需玩家设置的自动性能档位：手机连续两秒低于约 44 帧会切到 50 帧省电档，稳定八秒后自动恢复 60 帧均衡档。省电档把普通轨迹预测由 150 步降到 110 步，三体三分支时间线由 92 步降到 64 步并把缓存延长到 850 ms，同时减少尾焰粒子、黑洞透镜星点和历史轨迹长度；所有变化只影响绘制和预测采样，不改变飞船、天体、燃料、碰撞或任务判定。暂停菜单现在显示当前自动档位、世界/HUD 像素倍率、目标帧率和实际绘制帧率。十七组物理、任务、UI 与性能回归全部通过。

【v1.3.0 最终关：三体混沌穿越】
新增最终关“三体混沌穿越”：三颗等质量恒星从带随机扰动的八字形三体初态出发，同时依照彼此引力运动；玩家飞船也始终受到三颗恒星的叠加引力。每次整关重新开始都会生成新的宇宙种子、旋转角度、位置与速度微扰、两组恒星配对和时间锚方向，因此上一局的固定操作无法照搬；阶段回退会完整恢复当前宇宙的恒星位置、速度和种子，让玩家可以修正本局路线。任务目标是依次穿过两个随恒星运动的“时间锚”，再向外越过绿色逃逸圈并保持外向速度。

本关没有标准示范航线，改为实时计算三条短期“时间线影子”：青色表示左修正、白色表示继续滑行、粉色表示右修正。三条影子使用同一组三体引力向前积分，显示可能的分岔、预测恒星撞击点和当前最大分离距离；它们会持续重算，强调混沌系统短期可预测、长期对初始条件敏感。手机端将预测步数降到 92 并缓存 650 ms，桌面端使用 230 步与 220 ms 缓存，避免三套未来与三颗移动恒星造成卡顿。

新增三体专用世界图层和手机雷达：三颗恒星拥有独立颜色、运动尾迹和红色潮汐危险圈，画面显示紫色混沌边界、绿色逃逸边界、系统质心、两个移动时间锚及当前目标连线；小地图同步显示三色时间线和视角框。右上遥测新增最近恒星净空、距系统质心、混沌指数、时间线分岔和本局种子。教学模式完成固定一星；挑战模式中全程避开潮汐危险圈、剩余至少 20% 燃料各增加一星。新增 24 个随机宇宙、60 秒恒星积分与全功能静态回归，现有十七组测试全部通过。

【v1.2.2 深渊点火燃料与轨道重标定】
修复第九关挑战燃料过多、玩家能在远处直接加速逃逸的问题。挑战燃料箱改为 30%，第九关专用燃烧率使整箱最多提供约 13.8 u/s 速度增量；起点直接逃逸需要约 36.7 u/s，在半径 280 u 提前点火仍需约 14.0 u/s，因此烧完整箱也无法完成。默认无动力轨道的最近点由约 301 u 加深到约 235 u，安全高于 180 u 时间视界；在约 240 u 顺向点火只需约 12.8 u/s，数值积分可穿过 2200 u 救援门并剩余约 2.2% 燃料。

紫色深渊点火环缩到 205～275 u，引导只在进入 270 u 内才让推进按钮发光；二星条件同步改为半径 270 u 内点火，三星余油线改为 2%。首次轻点推进现在只解除世界待机，松手前不会消耗这只一次性燃料箱，避免启动操作偷吃燃料后让关卡无解。最终成功仍只检查玩家是否以正逃逸能量穿过救援门，没有加入必须照教学路线飞的隐藏判定。

【v1.2.1 黑洞时间手感与白炽吸积盘】
重做第九关的时间手感：飞船固有时钟继续使用 √(1−rₛ/r) 表示引力红移，远方观察到的位移、推进和转向则改用更强且连续的视界坐标速率。关卡起点保持正常响应，约 301 u 的默认最近点降至约四成运动速率，接近时间视界时逐渐降至约 2%，最终才冻结；黑洞关不再叠加普通推进子弹时间。右上角首行改为“远方观测速”，并同时保留本地速度与运动倍率，轨迹点也会在减速处自然变密。

修复火箭红移曾用矩形复合蒙版、导致看见长方形贴图底色的问题：红移现在只改变机身、尾翼、舷窗和尾焰自身颜色。吸积盘由彩色厚条带改成细薄的炽白盘面，新增被引力透镜抬到黑洞上、下方的后半盘弧像、纯白光子环、灰白外晕和少量旋转高亮物质结；屏幕红移暗角避开黑洞中心，不再把白盘整体染成橙紫色。手机轻量画质关闭阴影和高亮物质结，只保留白盘、双弧像、光子环与完整时间减速。

【v1.2.0 黑洞深渊点火】
新增第九关“黑洞深渊点火”：飞船从一条近黑洞椭圆轨道的远点出发，关机下潜到紫色深渊区域，在高速最近点顺向点火，利用奥伯特效应把有限推进剂转化为正逃逸能量，最后向外穿过绿色救援门。默认无动力轨道最近半径约 301 u，安全高于 180 u 时间视界；理想逃逸点火只需约 13.8 u/s 速度增量，挑战燃料留有充足修正余量。最终通关不依赖教学顺序，只验收飞船向外穿门且黑洞相对能量为正。

本关以远方任务控制中心视角表现相对论现象：用 √(1−rₛ/r) 缩放飞船固有时间、物理推进与转向，同时让远方信标、吸积盘和星光变化相对加速；靠近黑洞时增加星空引力透镜、光子环、吸积盘前后遮挡、引力红移、首尾潮汐差和沿径向逐渐拉长的飞船畸变。若飞船贴到视界，不触发爆炸或坠毁，而是把最后影像冻结在视界外并显示“飞船没有坠毁，但是你等不到它出来的那一天了”。科普明确说明这属于远方观察者的坐标图景，随飞船下落的宇航员会在有限固有时间内越过视界。

手机端使用简化透镜星空、纯色黑洞晕和无滤镜飞船，保留时间膨胀与轨道物理而减少渐变和阴影开销；重新安排第九关跟随构图，让黑洞、飞船和黄色预测轨迹在 390×844 竖屏中同时可见且不被右侧遥测遮住。新增黑洞专项数值与静态回归，当前十六组测试全部通过。

【v1.1.0 双星摆渡】

【v1.0.0 小行星拦截与可逆锚定】
新增第七关“小行星拦截”：一颗会在约百秒后撞击地球的小行星拥有独立质量、线速度、自转角速度和转动惯量，同时受地球、月球与火星引力。小行星质量也对应约 2.1 u/s² 的缩比表面引力和约 19 u/s 的逃逸速度，会帮助低速飞船自然落向表面；解除锚定时则会主动弹到逃逸速度以上。导航电脑绘制小行星未来轨迹、地月最近距离和“预计碰撞概率 99.9999%”撞击点；通关只验收最终轨道是否同时避开地球与月球并稳定 2.5 秒，不限制玩家按教学顺序操作。

本关支持三种自由解法：以低相对速度软着陆后直接低效率持续推进；点击“锚定并翻转”让机头抵住表面、发动机朝外，再用左右键调节 ±60° 喷口铰链高效推离；或高速直接撞击，牺牲飞船把线动量与角动量传给小行星。偏心推力和斜向撞击都会产生真实力矩并改变小行星自转，锚点固定在表面随之转动。锚定按钮可再次点击解除，火箭会继承小行星速度并轻轻弹离，恢复自由转向，之后还能换位置重新锚定。教学模式无限燃料固定一星；挑战模式给足 100% 燃料，保护飞船和剩余至少 18% 燃料各增加一星。

飞行画面右上角只保留视角、暂停和倍速；目录、轨迹、姿态、辅助与科普统一移入暂停菜单，电脑键盘说明也在此集中显示。姿态表和小地图现在可直接点按切换，小地图固定保留“轨道 / 全局”两种模式，不再有关闭状态。补齐 320×568 小屏竖屏与常见手机横屏的地图边界、工具栏和任务按钮布局，防止挤压或跑出屏幕。地球新增大气辉光、不规则大陆、冰盖、云层与昼夜明暗，月球新增月海、环形山、放射纹和明暗面。

【v0.5.8 连续多天体引力显示】
移除容易造成误解的“月球引力区”和所有人为引力范围圈。飞船在任何位置都同时受到地球、月球和火星引力，月球引力不会在某条边界突然开启。第四关 HUD 同时显示“月g / 地g”，可以看到接近月球时两者连续变化、月球引力逐渐占主导；真正的绕月束缚轨道要求保持不变。

【v0.5.7 地面复活与月球引力修复】
修复坠毁回到发射台后遗留“已离开发射台”状态、导致火箭不再随地球自转的问题；所有落在地球上的飞船现在保存地表经度并随地球持续转动。月球有效引力参数由 8.0e5 调整为 1.2e6，新增可见的月球引力区和 HUD 实时引力数值。第四关捕获阶段必须形成真正的月心束缚轨道，不能再像空间站对接一样仅靠接近和匹配速度通过。

【v0.5.6 发射模式权限修复】
90 u 垂直发射锁定现在仅用于默认的“随速偏转”新手模式。手动转向和纯惯性模式从离开发射台的第一帧起就拥有完整转向权限；在随速锁定过程中切换到这两种模式，也会立即解除锁定。月球阶段仍完全不使用发射锁定。

【v0.5.5 固定垂直发射流程】
地球起飞改为稳定的两段流程：离架时仍继承地球自转线速度；从地面到 90 u 高度期间，发射程序锁定火箭垂直于当地地面并暂时忽略转向输入。达到 90 u 后显示“控制已交给你”，一次性解除锁定并恢复玩家当前姿态模式。月球阶段不使用该锁定，不影响无伞手动着陆。

【v0.5.4 发射惯性参考系修复】
火箭在离开发射台时完整继承当地沿地球自转方向的线速度。近地随速模式扣除的是“离架瞬间已经继承的固定惯性速度矢量”，而不是每帧追逐旋转中的地面切向方向，消除了角速度落后→相对速度后偏→机头继续后转→坠毁的正反馈。离开 350 u 低空范围后自动切回地心轨道速度参考。

【v0.5.3 起飞姿态热修复】
修复随速模式起飞后会突然朝地球自转反方向偏转的问题。低空参考速度现在只扣除“同经度真实地表”的自转线速度，不再按照火箭当前高度虚构越来越大的共转速度；火箭垂直上升时不会被误判成逆着自转飞行。

【v0.5.2 目录点击热修复】
修复任务目录启用按住拖动后，指针捕获导致“开始任务”无法点击的问题。现在由目录统一识别点击坐标中的关卡卡片；只有真正拖动超过阈值时才会拦截点击，轻点卡片和“开始任务”按钮均可正常进入。

【v0.5.1 随速控制与目录拖动修复】
随速偏转现在会在每关开始时清除旧偏角：低空严格跟踪相对地面速度，高空跟踪轨道速度，月球附近跟踪相对月球速度，不再把当地垂直角与速度角混合而产生缓慢偏转。补强了触控取消、切后台和暂停时的按键释放。任务目录隐藏滚动条，改为按住卡片区域左右拖动。

【v0.5.0 月背动力着陆与性能优化】
新增第四关“月背动力着陆”：月球持续绕地球公转，月面纹理和着陆区按潮汐锁定同步旋转。玩家从地球发射，经停泊轨道和地月转移接近月球，消除相对速度后，在没有降落伞和自动扶正的情况下手动降落到月背。任务目录改为横向卡片并保留可见滚动条。轨迹预测从每秒高频 720 步改为缓存式 360/520 步，星空与航迹绘制也减少了无效负担。

【v0.4.0 空间站对接与任务目录】
新增第三关“空间站交会对接”：从地面发射，进入近地轨道，追赶空间站、匹配相对速度并低速完成对接。新增三关任务目录，记录每关最高得分与 1～3 星评价，成绩保存在当前设备。项目根目录新增“一键发布到GitHub Pages.cmd”，安装 Git for Windows 后双击即可把 dist 上传到已配置的 GitHub Pages 仓库。

【v0.3.7 卫星释放热修复】
手机端进入释放阶段后，推进键仍然保持可用；“释放卫星”按钮移到右上工具栏下方，不再占用推进区。同步轨道一旦通过阶段验收，点击释放就会立即完成部署，不再因随后产生的轻微轨道漂移而看似无响应。

【怎么玩】
双击 index.html 就能玩（用浏览器打开，推荐 Chrome / Edge）。

【安卓 / 苹果试玩】
推荐把 dist 文件夹发布到支持 HTTPS 的静态网站，再把网址发给朋友：
  安卓：用 Chrome 打开网址 → 浏览器菜单 →“安装应用”或“添加到主屏幕”
  苹果：用 Safari 打开网址 → 分享按钮 →“添加到主屏幕”
首次联网打开后，游戏会缓存到设备；之后可从主屏幕以独立窗口启动。

同一 Wi-Fi 下临时测试也可以在电脑上启动静态文件服务器，再用手机访问“电脑局域网 IP:端口”。
这种方式适合快速试玩；正式分享仍建议使用 HTTPS 网站。

【第一关 · 地球同步卫星】
跟着屏幕下方的分步指引，把卫星送上地球同步轨道：
  ① 进入环绕轨道 —— 短按起飞，高度 40–60 u 时向右压平，让黄色预测线闭合
  ② 抬升轨道     —— 沿速度方向点火，把远地点抬进金色环形带
  ③ 形成同步轨道 —— 在远地点再点火，让近、远地点都进入金色带，并匹配地球自转
  ④ 释放卫星     —— 确认顺行同步轨道稳定后按 E
                     （进阶挑战：开进绿色扇形"发射点正上空"再释放）
教学关燃料无限，大胆尝试！坠毁会回到当前阶段重来，不从头再来。

【第二关 · 载人航天返回】
从同步轨道开始，反推降低近地点，进入大气层后自动打开降落伞：
  ① 反推降轨 —— 机头朝速度反方向点火，让预测轨迹扎进地球
  ② 再入减速 —— 低空前把速度控制下来，等待降落伞打开
  ③ 垂直着陆 —— 机头朝上轻点推进，以 ≤17 的相对速度触地
落入绿色着陆区可达成完美着陆。

【第三关 · 空间站交会对接】
从地球发射进入近地轨道，利用高低轨道改变追赶速度，接近后消除相对速度，再以低速靠近空间站完成对接。

【第四关 · 月背动力着陆】
从地球发射并完成地月转移；接近月球后重点观察“月球相对速度”，短促反推完成捕获。绿色半球是始终背向地球的月背：没有降落伞，也没有自动垂直锁定，安全触地速度需 ≤15 u/s。绿色中央亮弧为高分区。

【操作】
  ↑ / W      点火推进（减速也是它：掉头朝尾向点火）
  ← → / A D  转向 / 调整姿态夹角
  C          切换姿态模式：手动转向(默认) / 纯惯性 / 随速偏转
  V          切换姿态表盘：世界固定 / 速度向上 / 机头向上
  T          开关未来轨迹辅助线（黄色虚线 = 松手后会怎么飞，橙圈=远地点 蓝圈=近地点）
  K          切换“跟随飞船 / 地球静止”视角
  B          切换“轨道雷达 / 全局导航”
  E          执行当前任务动作（手机点击画面中的任务按钮）
  H          隐藏 / 显示任务文字（不会改变游戏难度）
  M          切换飞行辅助 / 挑战模式
  按住空格    8 倍速（长距离等待用）
  P           暂停 / 继续
  L           下一关 / 回主菜单
  滚轮        缩放视野
  拖动画面    跟随模式松手后自动回到飞船；地球静止模式松手后停留在观察位置
  双指缩放    手机上双指捏合缩放地图，缩放中心跟随两指中点
  手机触控    左转 / 推进 / 右转按钮支持多指同时长按，可边转向边点火
  R          回到当前阶段检查点
  Shift+R    从本关开头重新开始

【姿态模式说明】
  随速偏转：机头始终和速度方向保持你设的夹角，←→ 调夹角。起飞自动垂直，入轨自动跟随
  手动转向：直接控制机头角度，简单直接
  纯惯性：  松手保持自旋，反向按键刹车，高手向

【缩比物理说明】
HUD 使用游戏单位 u / u/s，不代表真实米制数值。轨道机动的方向与因果关系遵循真实轨道力学，但天体尺寸、引力和时间均经过缩放。
