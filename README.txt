🛰️ 星际快递员 · 试玩版 v0.5.14

【v0.5.14 同步带释放判定修复】
修复辅助模式把可释放范围从画面可见的 ±150 u 黄色带错误放宽到 ±240 u、以及解锁后飞出带外仍能释放的问题。现在教学模式和挑战模式都严格使用画面中的真实黄色带：当前必须处于带内、顺行、径向升降率和同步残差稳定 1.5 秒才显示释放按钮；点击或按 E 时会再次验证。离开黄色带后按钮立即失效，返回后需要重新稳定，带外释放只会显示纠正提示而不会通关。

【v0.5.13 手机持续推进性能修复】
修复普通起飞推进也会持续触发子弹时间、导致画面像冻结的问题：现在只有同时推进和转向的精细机动才进入短暂慢动作，并按真实时间退出。尾焰粒子改为固定每秒生成、真实时间消失，手机最多保留 80 个，8 倍速也不会成倍堆积。手机画布像素倍率自动限制为 1.35，轨迹预测降为 240 步并延长缓存，星空数量减半；屏幕外天体不再绘制复杂表面，手机关闭高开销的大气模糊。全屏暗角渐变改为缓存复用，游戏物理与多天体引力精度保持不变。

【v0.5.12 手动开伞与手动对接】
中央任务按钮现在会随关卡切换动作：第一关释放卫星、第二关打开降落伞、第三关执行对接，电脑端统一使用 E 键。第二关取消自动开伞，高度进入 520 u 以下且正在下降时按钮出现并闪烁，必须由玩家点击；第三关满足最终距离和相对速度并稳定 0.8 秒后只开放“执行对接”按钮，不再自动吸附。直接跳过教学抵达最终条件的玩家同样可以获得对应按钮。

【v0.5.11 教学步骤自由跳过】
所有关卡的最终成功条件与教学阶段彻底解耦。第一关直接在黄色同步带或绿色目标段稳定飞行 1.5 秒即可开放卫星释放；第二关直接完成再入和安全着陆也会通关，开伞后会自动切到最终下降提示；第三关无论教学走到哪一步，只要进入低速对接窗口并稳定 0.8 秒即可对接；第四关可直接形成安全绕月轨道进入月背阶段，也可凭安全速度直接在月背着陆成功。教学现在只是建议路线，不再阻挡熟练玩家。

【v0.5.10 HUD 遮挡热修复】
桌面端右上角工具栏下移到遥测信息面板下方，不再遮挡速度、高度、相对速度和月球引力数据；手机竖屏与横屏继续使用各自的紧凑布局。

【v0.5.9 触屏仪表与星球美术打磨】
飞行画面右上角只保留视角、暂停和倍速；目录、轨迹、姿态、辅助与科普统一移入暂停菜单，电脑键盘说明也在此集中显示。姿态表和小地图现在可直接点按切换，小地图固定保留“轨道 / 全局”两种模式，不再有关闭状态。补齐 320×568 小屏竖屏与常见手机横屏的地图边界、工具栏和任务按钮布局，防止挤压或跑出屏幕。地球新增大气辉光、不规则大陆、冰盖、云层与昼夜明暗，月球新增月海、环形山、放射纹和明暗面。

【v0.5.8 连续多天体引力显示】
移除容易造成误解的“月球引力区”和所有人为引力范围圈。飞船在任何位置都同时受到地球、月球和火星引力，月球引力不会在某条边界突然开启。第四关 HUD 同时显示“月g / 地g”，可以看到接近月球时两者连续变化、月球引力逐渐占主导；真正的绕月束缚轨道要求保持不变。

【v0.5.7 地面复活与月球引力修复】
修复坠毁回到发射台后遗留“已离开发射台”状态、导致火箭不再随地球自转的问题；所有落在地球上的飞船现在保存地表经度并随地球持续转动。月球有效引力参数由 8.0e5 调整为 1.2e6，新增可见的月球引力区和 HUD 实时引力数值。第四关捕获阶段必须形成真正的月心束缚轨道，不能再像空间站对接一样仅靠接近和匹配速度通过。

【v0.5.6 发射模式权限修复】
90 u 垂直发射锁定现在仅用于默认的“随速偏转”新手模式。手动转向和纯惯性模式从离开发射台的第一帧起就拥有完整转向权限；在随速锁定过程中切换到这两种模式，也会立即解除锁定。月球阶段仍完全不使用发射锁定。

【v0.5.5 固定垂直发射流程】
地球起飞改为稳定的两段流程：离架时仍继承地球自转线速度；从地面到 90 u 高度期间，发射程序锁定火箭垂直于当地地面并暂时忽略转向输入。达到 90 u 后显示“控制已交给你”，一次性解除锁定并恢复玩家当前姿态模式。月球阶段不使用该锁定，不影响无伞手动着陆。

【v0.5.4 发射惯性参考系修复】
火箭在离开发射台时完整继承当地沿地球自转方向的线速度。近地随速模式扣除的是“离架瞬间已经继承的固定惯性速度矢量”，而不是每帧追逐旋转中的地面切向方向，消除了角速度落后→相对速度后偏→机头继续后转→坠毁的正反馈。离开 350 u 低空范围后自动切回地心轨道速度参考。

【v0.5.3 起飞姿态热修复】
修复随速模式起飞后会突然朝地球自转反方向偏转的问题。低空参考速度现在只扣除“同经度真实地表”的自转线速度，不再按照火箭当前高度虚构越来越大的共转速度；火箭垂直上升时不会被误判成逆着自转飞行。

【v0.5.2 目录点击热修复】
修复任务目录启用按住拖动后，指针捕获导致“开始任务”无法点击的问题。现在由目录统一识别点击坐标中的关卡卡片；只有真正拖动超过阈值时才会拦截点击，轻点卡片和“开始任务”按钮均可正常进入。

【v0.5.1 随速控制与目录拖动修复】
随速偏转现在会在每关开始时清除旧偏角：低空严格跟踪相对地面速度，高空跟踪轨道速度，月球附近跟踪相对月球速度，不再把当地垂直角与速度角混合而产生缓慢偏转。补强了触控取消、切后台和暂停时的按键释放。任务目录隐藏滚动条，改为按住卡片区域左右拖动。

【v0.5.0 月背动力着陆与性能优化】
新增第四关“月背动力着陆”：月球持续绕地球公转，月面纹理和着陆区按潮汐锁定同步旋转。玩家从地球发射，经停泊轨道和地月转移接近月球，消除相对速度后，在没有降落伞和自动扶正的情况下手动降落到月背。任务目录改为横向卡片并保留可见滚动条。轨迹预测从每秒高频 720 步改为缓存式 360/520 步，星空与航迹绘制也减少了无效负担。

【v0.4.0 空间站对接与任务目录】
新增第三关“空间站交会对接”：从地面发射，进入近地轨道，追赶空间站、匹配相对速度并低速完成对接。新增三关任务目录，记录每关最高得分与 1～3 星评价，成绩保存在当前设备。项目根目录新增“一键发布到GitHub Pages.cmd”，安装 Git for Windows 后双击即可把 dist 上传到已配置的 GitHub Pages 仓库。

【v0.3.7 卫星释放热修复】
手机端进入释放阶段后，推进键仍然保持可用；“释放卫星”按钮移到右上工具栏下方，不再占用推进区。同步轨道一旦通过阶段验收，点击释放就会立即完成部署，不再因随后产生的轻微轨道漂移而看似无响应。

【怎么玩】
双击 index.html 就能玩（用浏览器打开，推荐 Chrome / Edge）。

【安卓 / 苹果试玩】
推荐把 dist 文件夹发布到支持 HTTPS 的静态网站，再把网址发给朋友：
  安卓：用 Chrome 打开网址 → 浏览器菜单 →“安装应用”或“添加到主屏幕”
  苹果：用 Safari 打开网址 → 分享按钮 →“添加到主屏幕”
首次联网打开后，游戏会缓存到设备；之后可从主屏幕以独立窗口启动。

同一 Wi-Fi 下临时测试也可以在电脑上启动静态文件服务器，再用手机访问“电脑局域网 IP:端口”。
这种方式适合快速试玩；正式分享仍建议使用 HTTPS 网站。

【第一关 · 地球同步卫星】
跟着屏幕下方的分步指引，把卫星送上地球同步轨道：
  ① 进入环绕轨道 —— 短按起飞，高度 40–60 u 时向右压平，让黄色预测线闭合
  ② 抬升轨道     —— 沿速度方向点火，把远地点抬进金色环形带
  ③ 形成同步轨道 —— 在远地点再点火，让近、远地点都进入金色带，并匹配地球自转
  ④ 释放卫星     —— 确认顺行同步轨道稳定后按 E
                     （进阶挑战：开进绿色扇形"发射点正上空"再释放）
教学关燃料无限，大胆尝试！坠毁会回到当前阶段重来，不从头再来。

【第二关 · 载人航天返回】
从同步轨道开始，反推降低近地点，进入大气层后自动打开降落伞：
  ① 反推降轨 —— 机头朝速度反方向点火，让预测轨迹扎进地球
  ② 再入减速 —— 低空前把速度控制下来，等待降落伞打开
  ③ 垂直着陆 —— 机头朝上轻点推进，以 ≤17 的相对速度触地
落入绿色着陆区可达成完美着陆。

【第三关 · 空间站交会对接】
从地球发射进入近地轨道，利用高低轨道改变追赶速度，接近后消除相对速度，再以低速靠近空间站完成对接。

【第四关 · 月背动力着陆】
从地球发射并完成地月转移；接近月球后重点观察“月球相对速度”，短促反推完成捕获。绿色半球是始终背向地球的月背：没有降落伞，也没有自动垂直锁定，安全触地速度需 ≤15 u/s。绿色中央亮弧为高分区。

【操作】
  ↑ / W      点火推进（减速也是它：掉头朝尾向点火）
  ← → / A D  转向 / 调整姿态夹角
  C          切换姿态模式：随速偏转(默认) / 手动转向 / 纯惯性
  V          切换姿态表盘：世界固定 / 速度向上 / 机头向上
  T          开关未来轨迹辅助线（黄色虚线 = 松手后会怎么飞，橙圈=远地点 蓝圈=近地点）
  K          切换“跟随飞船 / 地球静止”视角
  B          切换“轨道雷达 / 全局导航 / 关闭小地图”
  E          释放卫星（手机在最后阶段点击屏幕下方“释放卫星”）
  H          隐藏 / 显示任务文字（不会改变游戏难度）
  M          切换飞行辅助 / 挑战模式
  按住空格    8 倍速（长距离等待用）
  P           暂停 / 继续
  L           下一关 / 任务目录
  滚轮        缩放视野
  拖动画面    跟随模式松手后自动回到飞船；地球静止模式松手后停留在观察位置
  双指缩放    手机上双指捏合缩放地图，缩放中心跟随两指中点
  手机触控    左转 / 推进 / 右转按钮支持多指同时长按，可边转向边点火
  R          回到当前阶段检查点
  Shift+R    从本关开头重新开始

【姿态模式说明】
  随速偏转：机头始终和速度方向保持你设的夹角，←→ 调夹角。起飞自动垂直，入轨自动跟随
  手动转向：直接控制机头角度，简单直接
  纯惯性：  松手保持自旋，反向按键刹车，高手向

【缩比物理说明】
HUD 使用游戏单位 u / u/s，不代表真实米制数值。轨道机动的方向与因果关系遵循真实轨道力学，但天体尺寸、引力和时间均经过缩放。
